# Product Mission Control 0.2.0-beta

The first beta, and the first release with a Windows installer. It is ready to hold real records:
your workspace is backed up, encrypted, and can be restored.

## Download and check

| File | What it is |
| --- | --- |
| `product-mission-control_0.2.0-beta_windows-x86_64_nsis-setup.exe` | The installer (per-user, no administrator rights) |
| `product-mission-control_0.2.0-beta_windows-x86_64_nsis-setup.exe.sha256` | Its SHA-256 checksum |

Check the installer before you run it:

```powershell
(Get-FileHash .\product-mission-control_0.2.0-beta_windows-x86_64_nsis-setup.exe -Algorithm SHA256).Hash.ToLower()
Get-Content .\product-mission-control_0.2.0-beta_windows-x86_64_nsis-setup.exe.sha256
```

The two values must match. The installer is **not code-signed**, so Windows SmartScreen warns about
it: choose **More info**, check the file name, then **Run anyway**.

Requirements: Windows 11 x64. The installer includes the WebView2 Runtime in case it is missing.

## What's new

- **Start the way you want.** The first screen offers your own workspace or a clearly labelled sample
  workspace; switch at any time in Settings.
- **Getting started.** Your workspace lists its setup in order — backup folder, recovery passphrase,
  first verified backup, Vault folder, first Product — each step read from the real state.
- **Encrypted backups and restore.** Backups go to a folder you choose, encrypted with a passphrase
  only you hold, and are verified before they count. Restore is a preview you can decline, and it
  works even when the current Ledger cannot be opened.
- **Your own Product Vault**, and **Evidence from a file** inside it.
- **Create and edit records** from the screens they belong to.
- **Six languages**, **System Health**, and an in-place upgrade path for future Ledger versions.

The full list is in the [changelog](../../CHANGELOG.md).

## Before you rely on it

- Write down your recovery passphrase, or keep it in a password manager. PMC cannot recover it, and
  without it a backup cannot be restored on any computer.
- Keep your backup folder on another drive if you can.
- Uninstalling never deletes your records, backups or Vault files. The
  [user guide](../user-guide/walkthrough.md#part-4--uninstall) lists where they are.

## Known limitations

- Review periods, Fact Packs and approved reports are not built yet.
- An Evidence file cannot be moved to a new location from the interface.
- A remembered recovery passphrase is stored once per Windows account. If you run a second PMC data
  folder on the same account (for example a test copy) and let it remember its passphrase, it replaces
  the first one's.
- In Portfolio, the View button sits at the right end of the table; on a narrow window, scroll the table
  sideways to reach it.
- Date fields show their placeholder in the Windows display language.
- No code signing, no automatic updates. To update, install the next release over this one; your
  records stay.
- Ledgers written by development builds before the first supported schema cannot be upgraded.
